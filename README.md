# Guilherme Dantas

Senior Software Engineer at [Hotmart](https://www.hotmart.com) · Belo Horizonte, Brazil

Lately I build harnesses and tooling around agents: the loop they run in, the files they may touch, and the checks that allow or deny an action. The model is one piece. The system around it is the work.

That shows up at Hotmart inside the internal platform for engineering teams. TypeScript, React, and Node on AWS. Shared context and observability still matter, because an agent that cannot see the company's systems is just a chat window.

[Site](https://guilherme-dantas.github.io) · [LinkedIn](https://www.linkedin.com/in/guilherme-dantascf)

## Public

- [stickler](https://github.com/Guilherme-Dantas/stickler) is a gate for Cursor, Claude Code, and Codex. A markdown dossier is the control. A hook reads it and allows or denies the action.
- [longplay](https://github.com/Guilherme-Dantas/longplay) is a small harness on an OpenAI-compatible endpoint, used by a Spotify picker that sizes an album to a workout. The phone calls the backend, not the model.

Older notes on gem5 and parallel algorithms are in [gem5-evaluation-computer-architectures](https://github.com/Guilherme-Dantas/gem5-evaluation-computer-architectures).
